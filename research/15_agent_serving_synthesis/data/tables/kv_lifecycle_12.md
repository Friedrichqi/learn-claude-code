*Key.* **edit**: the call's prompt diverges from the same chain's previous prompt more than 32 tokens before that prompt's end (an append-only call loses only the re-rendered tail block). **old tokens killed**: tokens of the previous prompt after the divergence point; their cached blocks can never be hit again. **shift-reusable (estimate)**: tokens after the edit point minus the chain's median append and a 64-token placeholder, i.e. surviving old content that prefix caching recomputes and a position-shifted reuse (research/10) would keep; an estimate, not a replay.

## 2. Garbage: dead blocks in the pool

| cell | minutes | evicted blocks | dead, % of evicted | live evictions with the owner idle, % | dead blocks produced per minute | same, % of the pool per minute |

*Key.* **dead**: an evicted cached block that its owner chain's next request cannot use (a superseded suffix after an edit, a re-rendered reply, the template tail), as the scheduler classified it at eviction. **dead blocks produced**: per call, the previous request's full blocks (prompt + output) minus the blocks still on the new prompt's common prefix, summed over the log.

*Key.* modeled with 11's pooled step model: a decode-only step costs 18.46 ms (weights and launch) + 0.028 ms per sequence + 77.3 ns per context token of every decoding sequence (≈ 256 KiB per token at ~3.4 TB/s, 70 % of the H200's 4.8 TB/s). | o1 | 887 | 9.1 | 1.7 | 4.2 | 5.0 | 45.6 |

*Key.* the rest of the pool is referenced by running requests. **dead (lower bound)**: cached-free blocks owned by a chain whose current request is running (its current prompt is referenced, so what it still owns in the free queue is an older version or a reply), plus, for a queued or idle chain, whatever it owns beyond its latest prompt's length. This is the capacity an edit-aware collector could hand back without losing a single reusable block.
